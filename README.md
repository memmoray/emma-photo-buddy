# Emma's Photography Assistant

Build a premium AI-powered virtual assistant website called Emma, the Photography Assistant.

The business is Golden Hour ATX Photography, a solo photography studio in Austin, Texas.

Emma is a friendly virtual studio manager who helps clients:

- Learn about photography packages

- Get pricing information

- Receive location recommendations

- Check availability

- Book photography sessions

- Receive confirmations and reminders

The homepage should feature Emma as the central character with a conversational AI assistant experience.

Include:

1. Hero section introducing Emma

2. Interactive AI chat experience

3. Package recommendation flow

4. Availability and booking flow

5. Confirmation
